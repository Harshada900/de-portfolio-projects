## Dashboard — Olist E-commerce Analytics

Interactive Power BI dashboard analyzing revenue trends, customer 
repeat behavior, seller performance, and delivery/review patterns 
for the Olist e-commerce dataset (2016–2018).

Connected live to Databricks Gold layer tables via SQL Warehouse.
